The contents of this folder are used to improve the rtmpose model, allowing it to synchronize the output of Operability Scores. 

Specifically, the Head has been improved, so the {improved head.py} file should be placed under {mmpose\models\heads\coold_cls_heads} and registered.

{An example of RTMPose Score's config.py} file provides a case configuration for training the RTMPose-score model.
